How Dijkstra's algorithm finds the shortest route

We model the campus as a weighted graph: each building is a node, each road is an edge, and each edge's weight is the road's length in metres — measured straight from the map you build (9 pixels = 1 metre, see the scale bar). Because every weight is non-negative, Dijkstra's greedy strategy is guaranteed to be optimal.

M is the central junction — a fixed hub of the campus. The four spoke roads (M↔C, M↔B, M↔D, M↔A) radiate outward from it to each building, and the four perimeter roads connect the buildings around the edge. Dragging a building changes its distance from M, so the spoke lengths follow automatically; M itself never moves.

put every distance = ∞, except Start = 0
while some unvisited node is reachable:
    pick the unvisited node u with the smallest distance   ← greedy choice
    mark u as visited (its distance is now final)
    for each neighbour v of u connected by an open road:
        if dist(u) + length(u→v) < dist(v):
            dist(v) = dist(u) + length(u→v)      ← "relaxing" the edge
            prev(v) = u
follow prev pointers back from the Destination → shortest path

Why the greedy choice is safe

When a node is picked with the smallest tentative distance, no other route can ever improve it — every alternative would have to pass through a node that is already farther away, and roads only add distance.

Complexity

  • With a simple scan for the minimum (as in this simulation): O(V²)
  • With a binary heap / priority queue: O((V + E) log V)
  • Here V = 5 nodes and E = 8 road segments, so it resolves almost instantly — the step log lets you watch it anyway.

Multi-stop routes

A route with stops (Start → Stop → Destination) is solved by running Dijkstra once per leg and adding the leg distances — each leg is independently optimal, so their sum is optimal.

Blocked roads

Blocking a road removes its segment(s) from the graph before the run — blocking a diagonal road removes both of its halves, because it is one road. If no route survives, the destination has been cut off from the start.
